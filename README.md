# exercism-java

Personal collection of Java solutions to exercises from [Exercism](https://exercism.org/tracks/java) — part of my ongoing journey to become a Java backend developer.

This repository is not just a solutions dump. It's a practice log: every folder here represents a concept I worked through, debugged, and (hopefully) understood a little better afterward — from basic syntax to core language features like arrays, strings, booleans, and object-oriented basics.

## 🎯 Purpose

- Track hands-on practice while learning Java, alongside a broader roadmap covering Java fundamentals, data structures & algorithms, Spring Boot, databases, and testing.
- Build muscle memory for reading requirements, writing tests, and implementing clean solutions.
- Serve as a personal reference I can look back on to see how my code — and my understanding — has evolved over time.

## 📂 Structure

Each top-level folder is a separate Exercism exercise, self-contained with its own source code and (where applicable) tests:

```
exercism-java/
├── hello-world/
├── lasagna/
├── bird-watcher/
├── annalyns-infiltration/
├── karls-languages/
├── calculator-conundrum/
├── jedliks-toy-car/
├── need-for-speed/
├── remote-control-competition/
├── squeaky-clean/
└── ...more to come
```

> 📌 This list keeps growing as I progress through the track — not every exercise is here yet, and new folders get added as I complete them.

## 🛠️ Tools & environment

- **Language:** Java
- **IDE:** IntelliJ IDEA (Community Edition)
- **Platform:** Exercism CLI / web editor
- **OS:** Windows

## 📈 Why this exists

This repo is one piece of a larger, structured learning plan aimed at landing a first role as a Java backend developer — alongside deeper dives into Spring Boot, JPA/Hibernate, concurrency, and backend best practices happening in other projects. Consider it the "reps" that build the fundamentals everything else is stacked on.
